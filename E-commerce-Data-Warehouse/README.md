# E-commerce Data Warehouse

A data engineering project using Snowflake and SQL to build and analyze an e-commerce data warehouse.

## Technologies

- Snowflake
- SQL

## Project Workflow

1. Database and schema setup
2. Table creation
3. Raw data ingestion
4. Data transformation
5. Customer and order analysis
6. Revenue analysis
7. Product and category analysis
8. Business dashboard queries

## Analysis

The project includes analysis of:

- Customer purchasing behavior
- Revenue by customer
- Revenue by product
- Revenue by country
- Revenue by category
- Daily revenue
- Top-selling products
- Average order value
- Customer segmentation

## Key Skills

- SQL
- Data Warehousing
- Data Transformation
- Data Analysis
- Snowflake
